# Pixel Python

Apprends Python comme un jeu : 5 mondes, 17 quêtes, 18 chapitres de cours avec quiz, XP, vies et quête du jour.

## Installer l'app

- **iPhone / iPad** : ouvre le site dans Safari, touche **Partager** puis **Sur l'écran d'accueil**.
- **Android** : ouvre le site dans Chrome puis touche **Installer** (ou menu ⋮ → **Ajouter à l'écran d'accueil**).

Une fois installée, l'app marche sans Internet.
